# Windows CLI adapters

Install and authenticate supported Cursor and Codex CLI tools separately using their official instructions. Conductor does not bundle accounts or install provider tools. Use each adapter's CLI help and a disposable fixture before assigning a real project.

Resolve the actual native executable from the shell that will launch it. Profiles pin executable identity, worker scope, repository/base and verifier; create a new profile after changing a pinned executable. A command that works interactively may inherit different environment or hook behavior under a child process.

Windows Cursor children use Windows PowerShell for hook commands and clear `MSYSTEM` to avoid selecting a Git Bash shell accidentally. Process progress reflects observed output and approved-file activity; see [progress](agent-progress.md). Keep provider homes, authentication and hooks private. A successful version check does not establish a successful coding assignment or safe hook behavior.
